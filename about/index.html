컨테이너 표준화

HTML과 NGINX 설정을 Docker 이미지로 패키징해 개발·검증·배포 환경의 차이를 줄입니다.

확장성과 고가용성

Replica 기반의 복수 Pod를 Worker Node에 분산 배치하여 장애 영향을 낮추고 수평 확장 기반을 확보합니다.

URL 기반 서비스 분리

NGINX Ingress가 메인, 입찰공고, 상세, 사업 소개 요청을 URL Path별 Service로 전달합니다.

공유 스토리지

NFS를 이용해 여러 웹 Pod가 동일한 정적 콘텐츠를 참조할 수 있도록 구성합니다.

프로젝트 구성

Docker

NGINX 기반 실행 환경을 이미지로 표준화해 동일한 웹 서버 구성을 반복 배포합니다.

Kubernetes

환경별 Namespace와 Replica 기반 배치로 개발·검증·운영 자원을 분리합니다.

NFS

192.168.2.80의 공유 스토리지에서 네 개 웹 콘텐츠를 환경별로 관리합니다.
